# ssforge-docs

Public documentation for **SSForge** mobile applications — privacy policies, terms, support pages, and store compliance content.

The application source code lives in separate private repositories. This repository is the single public home for legal and user-facing documentation published via **GitHub Pages**.

## About SSForge

SSForge builds lightweight, privacy-conscious utility apps focused on everyday tasks — conversion, scanning, and on-device processing without unnecessary cloud dependency.

**Contact:** [omerss.apps@gmail.com](mailto:omerss.apps@gmail.com)

## GitHub Pages

Documentation is served from the `/docs` folder on the `main` branch.

**Live site:** https://omersonmezsoy.github.io/ssforge-docs/

### One-time setup

1. Open **Settings** → **Pages** on this repository
2. **Source:** Deploy from a branch
3. **Branch:** `main` · **Folder:** `/docs`
4. Save and wait for deployment

See [docs/README.md](docs/README.md) for folder layout and maintainer notes.
